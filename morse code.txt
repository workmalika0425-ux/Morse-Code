# EyeMorse AI

Real-Time Eye Blink to Morse Code to English Communication System

## PROJECT OBJECTIVE

Build a real-time computer vision application that uses a normal webcam to detect a person's eye movements and intentional eye blinks.

The system must:

Camera
→ Face Detection
→ Eye Landmark Detection
→ Eye State Detection
→ Blink Detection
→ Blink Duration Measurement
→ Dot/Dash Classification
→ Morse Code Formation
→ Morse Character Decoding
→ Word Formation
→ Sentence Formation
→ Live User Interface

The final application should allow a user to communicate by intentionally blinking Morse code.

Example:

Short blink = .
Long blink = -

Sequence:

.... . .-.. .-.. ---

should become:

HELLO

## CORE COMPUTER VISION METHOD

Use facial landmarks to locate the eyes.

Calculate Eye Aspect Ratio (EAR).

Use temporal eye-state analysis to determine:

OPEN
CLOSING
CLOSED
OPENING

Measure intentional blink duration.

Classify:

SHORT BLINK → DOT (.)
LONG BLINK → DASH (-)

Use configurable thresholds rather than hard-coding values throughout the project.

## MORSE TIMING MODEL

The system must distinguish:

Blink duration → Dot or Dash

Short pause → same Morse character

Medium pause → next character

Long pause → word boundary

These values must be configurable.

Do not assume that one timing configuration works perfectly for every user.

## MORSE DECODER

Implement the complete International Morse alphabet:

A-Z
0-9

Also support common punctuation where practical.

The decoder must use a clean dictionary/data structure.

## SENTENCE BUILDER
